## 一、字符串的本质：字符数组 + `'\0'`

### 核心结论

> **C 语言里没有"字符串类型"。字符串就是「一串字符 + 结尾的 `'\0'`」。**

### 实测（`string_basic.c`）

```c
char s[] = "cat";
printf("%u\n", sizeof(s));    /* 输出 4，不是 3！ */
```

**内存里其实是这样：**

```
   s[0] = 'c'    (编码值 99)
   s[1] = 'a'    (编码值 97)
   s[2] = 't'    (编码值 116)
   s[3] = '\0'   (编码值 0)   <-- 看不见的结尾标记
```

**3 个字母却占 4 字节，多的那 1 字节就是 `'\0'`。**

### `'\0'` 是干什么的

**它是"到此结束"的标记。** 所有字符串函数（`printf("%s")`、`strlen`、`strcpy`）都是**一直读到 `'\0'` 才停**。

**⚠️ 所以忘写 `'\0'` 是经典 bug** —— 程序会一直往后面读，打出乱码甚至崩溃。

### `sizeof` 和 `strlen` 不一样

```
sizeof(s) = 4   <-- 数组总大小（含 '\0'）
strlen(s) = 3   <-- 实际字符数（不含 '\0'）
```

**差 1，就差在那个看不见的 `'\0'` 上。**

## 二、`char s[]` 和 `char *p` 的本质区别 ⭐

```c
char  s[] = "cat";      /* 数组：在栈上拷贝一份，可读可改 */
char *p   = "cat";      /* 指针：指向只读数据区的字面量 */
```

### 实测对比

```
char s[] = "cat";   sizeof(s) = 4  <-- 整个数组
char *p  = "cat";   sizeof(p) = 8  <-- 只是个指针

两者都能打印: s = cat,  p = cat
```

**⚠️ 表面看它们一样，但内存位置完全不同。**

### 画个图

```
char s[] = "cat";
   ┌───┬───┬───┬────┐
栈 │ c │ a │ t │ \0 │      ← 自己的内存，可写
   └───┴───┴───┴────┘
     ↑ s

char *p = "cat";
   ┌──────────┐
栈 │  地址    │ ──────┐     ← p 自己只是个纸条
   └──────────┘       │
     ↑ p              ↓
                 ┌───┬───┬───┬────┐
      只读数据区 │ c │ a │ t │ \0 │  ← 不能写！
                 └───┴───┴───┴────┘
```

### 用地址一眼看出区别（`string_literal.c`）

```
a 的地址 = 000000000062FDD0   <-- 栈 (可写)
b 指向的 = 0000000000404008   <-- 只读数据区 (不可写)
```

**地址开头不一样：`0x62xxxx` 是栈，`0x40xxxx` 是全局/只读区。**

**（这个判断方法在 7.4 讲野指针时也用过 —— 同一个技巧。）**

## 三、用指针遍历字符串

### 两种等价写法

```c
char s[] = "hello";
char *p;

/* 写法 A：显式比较 '\0' */
for (p = s; *p != '\0'; p++) {
    printf("%c", *p);
}

/* 写法 B：利用 '\0' 的值就是 0 */
p = s;
while (*p) {          /* 遇到 '\0'（值为 0）就停 */
    printf("%c", *p);
    p++;
}
```

**实测输出：`hello`**

**`while (*p)` 更简洁，因为 `'\0'` 的编码值就是 `0`，在条件里等价于"假"。**

### 顺便就得到了字符串长度

```c
p = s;
while (*p) p++;
printf("%d\n", (int)(p - s));   /* 5 */
```

**指针走完后的位置减去开头 = 字符个数。** 这就是 `strlen` 的原理。

### 自己实现 `strlen`

```c
int my_strlen(const char *s) {
    const char *q = s;
    while (*q != '\0') {
        q++;
    }
    return (int)(q - s);
}
```

**实测：`"pointer"` 的长度 = 7** ✅

## 四、字符串字面量不能改 ⚠️（本节最重要的坑）

### 回到开场问题

```c
char  a[] = "hello";
char *b   = "hello";

a[0] = 'H';     // ✅ 能跑（改自己的栈内存）
b[0] = 'H';     // ❌ 崩溃！Segmentation fault
```

**答案是第三个选项：第一个能跑，第二个崩溃。**

### 为什么

| 写法 | `"hello"` 存在哪 | 能改吗 |
|---|---|---|
| `char a[] = "hello"` | **拷到栈上**（自己的数组）| ✅ 能改 |
| `char *b = "hello"` | **只读数据区**（字面量本身）| ❌ 不能改 |

**`char *b = "hello"` 只是让 `b` 指向了那块只读区域 —— 修改它就是写只读内存，操作系统直接把进程杀掉。**

### 想亲眼看崩溃

`string_literal.c` 里有个 `crash_demo()` 函数，默认被注释掉了。**取消注释后**：

```c
/* crash_demo(); */     ← 去掉注释
```

**重新编译运行，你会看到：**

```
Segmentation fault (core dumped)
```

**（注意：本机 SAC 可能拦这个 exe，见文末说明。用 F5 调试运行也可以看到。）**

## 五、常用字符串函数（都在 `<string.h>`）

### `strlen` —— 取长度

```c
strlen("hello")     /* 5，不含 '\0' */
```

### `strcpy` —— 复制（注意：不是赋值！）

```c
char s1[20] = "hello";
char s2[20];

s2 = s1;              /* ❌ 编译错误！数组名是地址，不能整体赋值 */
strcpy(s2, s1);       /* ✅ 正确 */
```

**实测：`strcpy(s2, s1)` 之后 `s2 = "hello"`**

### ⭐ 指针赋值 vs `strcpy`（关键区别）

```c
char s1[20] = "hello";
char *p = s1;         /* 指针赋值 */

p[0] = 'H';
printf("%s\n", s1);   /* 输出 "Hello" —— s1 也变了！ */
```

**实测：**

```
p = s1 之后: p = "hello"
改 p[0]='H' 之后: s1 = "Hello"   <-- s1 也变了!
=> 指针赋值只是复制了「地址」, 两份指着同一块地
```

**对比 `strcpy`：**

```
strcpy 之后改 s4[0]: s3 = "hello", s4 = "Hello"
=> strcpy 复制的是内容, 改一个不影响另一个
```

| | 做了什么 | 结果 |
|---|---|---|
| `p = s1` | 复制**地址** | 两个指针指向**同一块内存**，改一个另一个也变 |
| `strcpy(dst, src)` | 复制**内容** | 两块**独立**内存，互不影响 |

**这个区别非常重要，和 7.4 讲的"传值 vs 传地址"是同一个思想。**

### `strcat` —— 追加

```c
char s1[20] = "hello";
strcat(s1, " world");     /* s1 变成 "hello world" */
```

### `strcmp` —— 比较（⚠️ 返回的不是真假）

```c
strcmp("abc", "abc")   /*  0  ← 相等 */
strcmp("abc", "abd")   /* -1  ← 前者小 */
strcmp("abd", "abc")   /*  1  ← 前者大 */
```

**实测确认。⚠️ 陷阱：**

```c
if (strcmp(a, b)) { ... }      /* ❌ 这样写是"不相等"时才进！ */
if (strcmp(a, b) == 0) { ... } /* ✅ 相等 */
```

**因为相等时返回 `0`，而 `0` 在 `if` 里是假。** 很多人在这里翻车。

### 自己用指针实现 `strcpy`

```c
char *my_strcpy(char *dest, const char *src) {
    char *start = dest;          /* 记住开头，最后要返回它 */
    while (*src != '\0') {
        *dest = *src;            /* 一个字符一个字符地抄 */
        dest++;
        src++;
    }
    *dest = '\0';                /* ⚠️ 别忘了补结尾的 '\0'！ */
    return start;
}
```

**（可以简写成 `while (*dest++ = *src++);` —— 一行搞定，但初学不建议这么写。）**

**⚠️ 忘记补 `'\0'` 是经典 bug** —— 后面会打出乱码，因为字符串函数找不到结尾。

## 六、字符串数组：两种写法

```c
/* 法一：二维字符数组 —— 每行定长 */
char a[3][16] = {"apple", "banana", "cherry"};

/* 法二：指针数组 —— 每行存地址 */
const char *b[3] = {"apple", "banana", "cherry"};
```

### 实测对比

```
char a[3][16]    总大小 = 48 字节  (3 x 16, 每行固定, 不管实际多长)
const char *b[3] 总大小 = 24 字节  (3 x 8)
```

| | 存什么 | 大小 | 能改吗 |
|---|---|---|---|
| `char a[3][16]` | **字符本身** | 定长，**会浪费** | ✅ 能改 |
| `const char *b[3]` | **地址** | 灵活**省空间** | ❌ 字面量不能改 |

**"apple" 只有 5 个字符，但 `a[0]` 占了 16 字节 —— 这就是浪费。**

**指针数组更省空间，但代价是内容不能改。**

## 七、⚠️ 常见错误对照表（务必记住）

| 错误写法 | 后果 | 正确写法 |
|---|---|---|
| `char *p="hi"; p[0]='H';` | 💥 崩溃（改只读区）| `char p[]="hi"; p[0]='H';` |
| `char s[10]; s = "hi";` | 编译错误（数组不能整体赋值）| `strcpy(s, "hi");` |
| `printf("%s", *p);` | 错（`%s` 要**地址**，`*p` 是字符）| `printf("%s", p);` |
| `printf("%c", p);` | 错（`%c` 要**字符**）| `printf("%c", *p);` |
| `if (strcmp(a,b))` | 逻辑反了 | `if (strcmp(a,b) == 0)` |
| 忘了写 `'\0'` | 打出乱码 / 崩溃 | 手动补 `*dest = '\0';` |

### `%s` 和 `%c` 的区别（实测）

```
*(p+1) 是字符:  %c -> a
p       是地址:  %s -> cat     (%s 从该地址一直打到 '\0')
p+1     从 'a' 开始 -> at
```

> **`%s` 要的是【地址】，不是字符！**
> **`printf("%s", *p)` 是错的 —— 这会让程序去读一个很小的地址，直接崩溃。**

## 八、本节总结

```
① 字符串 = 字符数组 + 结尾的 '\0'
   → sizeof 含 '\0'，strlen 不含，差 1

② char s[] 和 char *p 的本质区别
   → s[] 在栈上（可写），*p 指向只读区（不可写）
   → 用地址开头判断：0x62xxxx = 栈，0x40xxxx = 只读区

③ 用指针遍历：while (*p) { ...; p++; }
   → 走完后 p - 开头 = 字符串长度（strlen 的原理）

④ ⚠️ 改字符串字面量会崩溃
   → 要改就用 char s[]，或先拷到可写缓冲区

⑤ 指针赋值 vs strcpy
   → p = s1      复制地址，两块指向同一处，改一个都变
   → strcpy(d,s) 复制内容，两块独立

⑥ %s 要地址，%c 要字符 —— 别搞混
```
